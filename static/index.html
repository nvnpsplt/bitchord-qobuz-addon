📱 How to Connect to BitChord App

1

Open BitChord

Ensure your Android device running BitChord is connected to the same Wi-Fi network (or reachable via reverse proxy / Cloudflare tunnel).

2

Navigate to Sources

Go to Settings → Sources → Add Module Source (or Add Custom Addon).

3

Paste Manifest URL

Paste your addon link (e.g. http://192.168.X.X:8080/manifest.json) and tap Add / Verify.

4

Prioritize Source

Drag the Qobuz FLAC source to the top of your sources list. BitChord will now match and stream High-Res FLAC directly for all playback!
